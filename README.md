# The Long Way Here

A four and a half minute journey through the 13.8 billion year history of the atoms in your body.

**Live:** https://paragontasx.github.io/the-long-way-here/

It is a single HTML file, `index.html`. WebGL2 draws every star, planet and cloud, and Web Audio synthesises every note, so there are no images, video or libraries. Everything is generated on your device while it plays. The score is tuned to hydrogen: its four visible spectral lines, lowered forty octaves, are G♯, C♯, D♯ and E.

Best on a desktop browser with sound on. It plays itself. Scroll, drag or use the arrow keys to take control at any time, and press space to pause. Add `?t=120` to the address to start 120 seconds in.

It contains a few bright flashes. There is a "soften the flashes" option on the first screen, and it is applied automatically if your system asks for reduced motion.
